## 二、接口清单

| 接口 | 方法 | 状态 | 说明 |
| --- | --- | --- | --- |
| /api/v1/data/enterprises/import | POST | 可用 | 批量导入企业，支持 dry_run |
| /api/v1/data/policies/import | POST | 可用 | 批量导入政策，支持 dry_run |
| /api/v1/data/import/status | GET | 可用 | 质量报告 |
| /api/v1/enterprises | GET | 可用 | D2 筛选，支持多条件，返回命中原因 |
| /api/v1/enterprises/{id}/profile | GET | 可用 | D3 画像，6 维度带 provenance |
| /api/v1/data/segments/coverage | GET | 可用 | C1 环节覆盖统计，支持按地域筛选 |
| /api/v1/policies/match | GET | 可用 | C2 政策匹配检索，支持企业 ID 或行业+地域 |

健康检查：GET /api/v1/health

启动方式：

```
cd SE-project
python -m pip install -r requirements.txt
python -m uvicorn src.main:app --host 127.0.0.1 --port 8000
```

服务启动会自动检查数据库：表不存在会建表并导入环节字典，数据为空会从清洗后 CSV 填充企业政策。无需手动重建。如需强制重建，运行 `python data/import_data.py`。

## 三、各岗位交接事项

### 短板识别岗

- 可用接口：B1 筛选、C1 环节覆盖统计、A3 质量报告。
- 需确认：5 个环节的口径，尤其是浙江创芯按实际业务归到晶圆制造是否认可。环节字典见 data/环节字典_草稿.csv。
- 数据现状：芯片设计 30、半导体材料 9、晶圆制造 4、先进封装 4、半导体设备 3。制造、封测、设备环节企业偏少，便于做短板演示。

### 评分引擎岗

- 可用接口：B2 画像、B1 筛选。
- 需确认：画像 6 维度的字段与 provenance 是否满足 D4 打分需要。字段取值见 数据岗接口契约_v1.0.md 第 5 节 B2 示例。
- 数据现状：27 家企业 6 维度齐全；其余企业有维度缺失，接口在 missing_dims 中列出。评分时需决定跳过还是按缺失处理。
- 边界：画像接口不返回任何评分字段，评分归 D4。

### 方案生成岗

- 可用接口：B2 画像、C2 政策匹配检索。
- 可用数据：政策库 10 条，均为公开政策原文摘录，来源链接可核对。见 data/政策_清洗后.csv。
- 需确认：画像字段与政策文本是否够生成方案。
- 边界：数据岗只提供企业事实与政策原文，方案文本由方案生成岗组织。

### 组长

- 交付物：本说明、docs/A3_质量报告.json、接口基址、数据岗接口契约_v1.0.md、数据岗导入执行计划_v1.0.md。
- 验收对照：契约第一节四条交付标准全部达标。
- 接口状态：七个接口（A1/A2/A3/B1/B2/C1/C2）全部可用并自测通过。
