## 2. 原型怎么跑

直接双击 prototype/index.html，用 Chrome 或 Edge 打开，不用联网、不用装依赖。

1. 左边是补链任务列表（D1 接口还没交付，现在用 C1 环节统计临时派生），点任务可以过滤右边候选企业。
2. 候选企业表格里看画像标签和命中原因；D4 评分还没交付，评分列显示"待评分"，可以先按画像和政策生成草稿。
3. 点"生成方案"，等生成动画结束后打开详情抽屉，能看画像 6 维、推介要点、政策包、谈判策略、行动计划和版本时间线。
4. "方案台账"页签看方案状态和生成方式；可以提交审核、定稿或驳回（驳回要填意见）、重新生成（出新版本）、导出 Markdown。
5. 状态流转：待生成 → 草稿 → 待审核 → 已定稿；驳回退回草稿；定稿后重新生成另存新版本，旧版本归档只读。

接真实后端时，把 index.html 里引入 mock-api.js 的那行换成 api-client.js，页面逻辑不用改。
